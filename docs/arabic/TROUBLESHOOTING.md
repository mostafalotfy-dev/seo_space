# دليل استكشاف الأخطاء وإصلاحها

## مشكلات التثبيت

### "npm: command not found"

**المشكلة:** npm غير مثبت أو غير موجود في PATH

**الحلول:**
1. ثبّت Node.js من https://nodejs.org/
2. اختر إصدار LTS (يُنصح بـ v18 أو أحدث)
3. أكمل التثبيت وأعد تشغيل الطرفية
4. تحقق: `node --version` و`npm --version`

---

### "npm ERR! code EACCES"

**المشكلة:** رفض الإذن (macOS/Linux)

**الحلول:**
```bash
# الخيار 1: إصلاح أذونات npm
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
export PATH=~/.npm-global/bin:$PATH

# الخيار 2: استخدام sudo (غير موصى به)
sudo npm install -g npm

# الخيار 3: إصلاح أذونات المجلد
sudo chown -R $(whoami) /usr/local/lib/node_modules
```

---

### أخطاء "Module not found"

**المشكلة:** التبعيات غير مثبتة أو تالفة

**الحلول:**
```bash
# إعادة تثبيت كاملة
rm -rf node_modules package-lock.json
npm cache clean --force
npm install

# أو إعادة التثبيت
npm install --legacy-peer-deps
```

---

### التثبيت يتوقف أو يستغرق وقتاً طويلاً

**المشكلة:** مشكلات في الشبكة أو المرايا

**الحلول:**
```bash
# تغيير سجل npm
npm config set registry https://registry.npmjs.org/

# محاولة التثبيت بإعدادات مختلفة
npm install --no-optional

# التحقق من اتصال الشبكة
ping registry.npmjs.org
```

## مشكلات التجميع

### فشل تجميع Pug بصمت

**المشكلة:** gulp.cjs يحتوي على أخطاء

**الحلول:**
1. تحقق من إصدار Node.js: `node --version` (يجب v18+)
2. تأكد من وجود gulp.cjs: `ls gulp.cjs`
3. شغّل التجميع مباشرةً لرؤية الأخطاء:
   ```bash
   npm run gulp
   ```
4. تحقق من أخطاء البناء الجملي في index.pug

---

### "SyntaxError in Pug template"

**المشكلة:** بناء جملة Pug غير صحيح في index.pug

**أمثلة على الأخطاء:**
```
• Error: Unexpected token
• Error: Unexpected indent
• Error: Unexpected end of file
```

**الحلول:**
1. تحقق من المسافة البادئة (Pug حساس للمسافات البادئة)
2. تأكد من إغلاق جميع الوسوم بشكل صحيح
3. تحقق من عدم تطابق الأقواس
4. استخدم إضافة Pug لـ VS Code لإبراز البناء الجملي
5. انتقل إلى رقم السطر في رسالة الخطأ

---

### ملفات الإخراج لا تُولَّد

**المشكلة:** ملفات HTML لا تُنشأ بعد التجميع

**الحلول:**
1. تحقق من المجلد الحالي (يجب أن تكون في جذر المشروع)
2. تأكد من صحة مسار إخراج gulp.cjs
3. تأكد من تثبيت pug:
   ```bash
   npm list pug
   ```
4. أعد تشغيل البناء:
   ```bash
   npm run gulp
   ```

---

## مشكلات التطوير

### المتصفح لا يعرض التغييرات

**المشكلة:** ذاكرة التخزين المؤقت أو وضع المراقبة لا يعمل

**الحلول:**
1. **التحديث القسري للمتصفح:**
   - Windows/Linux: Ctrl+Shift+Delete
   - macOS: Cmd+Shift+Delete
2. **تعطيل الذاكرة المؤقتة في DevTools:**
   - اضغط F12 ← تبويب Network
   - ضع علامة على "Disable cache"
3. **إعادة تشغيل وضع المراقبة:**
   ```bash
   # أوقف المراقبة الحالية (Ctrl+C)
   npm run watch
   ```
4. **تأكد من تشغيل المراقبة فعلاً:**
   - يجب أن تظهر رسالة "watching for changes"

---

### مشكلات CSS/الأنماط

**المشكلة:** الأنماط لا تُطبَّق أو الألوان خاطئة

**الحلول:**
1. **مسح الذاكرة المؤقتة:**
   - اضغط Ctrl+F5 (تحديث قسري)
2. **تحقق من تحميل ملف CSS:**
   - اضغط F12 ← تبويب Network
   - ابحث عن ملفات CSS (يجب أن تظهر بحالة 200)
3. **تأكد من مسار CSS في HTML:**
   ```html
   <!-- يجب أن يكون: -->
   <link rel="stylesheet" href="assets/css/main.css">
   ```
4. **تحقق من تفسير CSS:**
   - استخدم DevTools للمتصفح لفحص العنصر
   - راقب قواعد CSS المُطبَّقة
5. **إعادة التجميع القسرية:**
   ```bash
   npm run gulp
   ```

---

### أخطاء JavaScript في وحدة التحكم

**المشكلة:** وحدة التحكم تعرض رسائل خطأ حمراء

**الحلول:**
1. **تحقق من تحميل jQuery أولاً:**
   - اضغط F12 ← تبويب Network
   - jquery.min.js يجب أن يُحمَّل قبل السكريبتات الأخرى
2. **تأكد من مسارات ملفات السكريبت:**
   - تحقق من سمات src للسكريبت في HTML
   - يجب أن تكون: `assets/js/main.js`
3. **أصلح أخطاء البناء الجملي:**
   - انظر إلى رقم السطر في الخطأ
   - تحقق من main-custom.js أو ملفات JS أخرى
4. **اختبر في وحدة التحكم:**
   - اضغط F12 ← تبويب Console
   - اكتب `$` — إذا أعاد دالة، فـ jQuery مُحمَّل

---

### النموذج لا يُرسَل

**المشكلة:** نموذج التواصل لا يُرسَل

**الحلول:**
1. **تحقق من أن النموذج له action:**
   ```html
   <form action="https://formspree.io/f/YOUR_ID" method="POST">
   ```
2. **تأكد من أن حقول النموذج لها الاسم (name):**
   ```html
   <input name="email" type="email">
   <textarea name="message"></textarea>
   ```
3. **تحقق من أخطاء التحقق:**
   - راقب وحدة تحكم المتصفح للأخطاء
   - تحقق من تنسيق حقل البريد الإلكتروني
4. **اختبر إرسال النموذج:**
   - افتح DevTools ← تبويب Network
   - جرّب إرسال النموذج
   - تحقق مما إذا كان طلب POST مُرسَلاً

## مشكلات التوطين

### الترجمات لا تظهر

**المشكلة:** الصفحة تعرض مفاتيح الترجمة بدلاً من النص

**الحلول:**
1. **تأكد من وجود ملفات الترجمة:**
   ```
   locals/en.json
   locals/ar.json
   ```
2. **تحقق من صحة بناء JSON:**
   - استخدم https://jsonlint.com/
   - يجب أن تتطابق الأقواس
3. **تأكد من تطابق المفاتيح في كلا الملفين:**
   - الملفات الإنجليزية والعربية يجب أن يكون لهما نفس الهيكل
4. **تحقق من تحميل الترجمة في Pug:**
   ```pug
   h1 #{t('title.main')}
   ```

---

### النص العربي لا يُعرض

**المشكلة:** الحروف العربية تظهر بشكل خاطئ أو لا تظهر

**الحلول:**
1. **تحقق من الترميز:**
   - رأس HTML يجب أن يحتوي على: `<meta charset="UTF-8">`
2. **تأكد من أن الخط يدعم العربية:**
   - تحقق من إعلان @font-face
   - أو استخدم خطوط النظام: `font-family: Arial, sans-serif;`
3. **تحقق من سمة RTL:**
   - يجب أن يحتوي HTML على: `dir="rtl"` عندما تكون lang هي 'ar'
4. **تأكد من أن ar.json مُشفَّر بـ UTF-8:**
   - احفظ الملف بترميز UTF-8 في المحرر

---

### تبديل اللغة لا يعمل

**المشكلة:** تغيير اللغة لا يُحدِّث النص

**الحلول:**
1. **أعد التجميع بلغة مختلفة:**
   ```bash
   # عدّل .env
   LANG=ar
   npm start
   ```
2. **تحقق من وجود أزرار اللغة:**
   - ابحث عن زر/قائمة اللغة في HTML
   - تحقق من main-custom.js لمعالج الحدث
3. **امسح الذاكرة المؤقتة وأعد التحميل:**
   - التحديث القسري للمتصفح (Ctrl+F5)

---

## مشكلات السمة والألوان

### الألوان لا تتغير

**المشكلة:** تغييرات السمة لا تظهر

**الحلول:**
1. **تأكد من تحميل CSS لوحة الألوان:**
   - تحقق من أن HTML يحتوي على: `<link href="assets/css/color-palette/navy.css">`
2. **تحقق من بناء جملة متغير CSS:**
   ```css
   :root {
     --main-color: #FFFFFF;
   }
   ```
3. **تحديث قسري لمسح الذاكرة المؤقتة:**
   - Ctrl+F5 أو Cmd+Shift+R
4. **تحقق من سمة data-theme:**
   ```html
   <!-- يجب أن تكون على body: -->
   <body data-theme="dark">
   ```

---

### تبديل الوضع الداكن/الفاتح لا يعمل

**المشكلة:** تبديل الوضع لا يغير الألوان

**الحلول:**
1. **تحقق من وجود زر التبديل:**
   - ابحث عن زر أو تبديل في الرأسية
   - تحقق من main-custom.js لوظيفة التبديل
2. **تأكد من أن CSS السمة يحتوي على كلا الوضعين:**
   ```css
   :root,[data-theme="dark"] { /* الوضع الداكن */ }
   [data-theme="light"] { /* الوضع الفاتح */ }
   ```
3. **تحقق من عمل localStorage:**
   - اضغط F12 ← Application ← localStorage
   - يجب أن تظهر تفضيل السمة
4. **اختبر يدوياً في وحدة تحكم المتصفح:**
   ```javascript
   document.body.dataset.theme = 'light'
   // يجب أن تتحدث الصفحة إلى الوضع الفاتح
   ```

## مشكلات الأداء

### الصفحة تُحمَّل ببطء

**المشكلة:** وقت تحميل الصفحة بطيء

**الحلول:**
1. **تحقق من أحجام ملفات الصور:**
   - الصور في assets/images/ يجب أن تكون < 100KB كل منها
   - استخدم TinyPNG.com للتحسين
2. **تحقق من الشبكة في DevTools:**
   - اضغط F12 ← تبويب Network
   - أعد تحميل الصفحة
   - ابحث عن الملفات الكبيرة (> 1MB)
3. **تصغير CSS/JS:**
   - Bootstrap يجب أن يكون الإصدار المُصغَّر
   - Gulp يتولى التصغير تلقائياً
4. **استخدم CDN للمكتبات:**
   - Bootstrap وجQuery يمكن تحميلهما من CDN
5. **تحقق من الموارد التي تحجب العرض:**
   - انقل السكريبتات غير الحرجة إلى defer

## مشكلات التصميم سريع الاستجابة

### الموقع غير متجاوب على الجوال

**المشكلة:** التخطيط ينكسر على الشاشات الصغيرة

**الحلول:**
1. **تحقق من وسم viewport في meta:**
   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1.0">
   ```
2. **اختبر بأدوات DevTools للمتصفح:**
   - اضغط F12 ← تبديل شريط الأجهزة
   - اختبر أحجام شاشات مختلفة
3. **تحقق من شبكة Bootstrap:**
   - الأعمدة يجب أن تتكدس على الجوال
   - `col-md-6` يجب أن يكون 100% على الشاشات الصغيرة
4. **أصلح مشكلات التجاوز (overflow):**
   ```css
   /* أضف إلى main.css إذا لزم: */
   body { overflow-x: hidden; }
   ```

## مشكلات توافق المتصفح

### يعمل في Chrome لكن ليس في Firefox

**المشكلة:** أخطاء JavaScript في متصفح محدد

**الحلول:**
1. **تحقق من وحدة تحكم المتصفح:**
   - المتصفحات المختلفة قد تعرض أخطاء مختلفة
2. **اختبر توافق jQuery:**
   - إصدارات jQuery القديمة قد لا تدعم جميع الميزات
3. **تحقق من بادئات CSS:**
   - بعض خصائص CSS قد تحتاج إلى -webkit- أو -moz- أو -o-
4. **حدّث المتصفح:**
   - جرّب أحدث إصدار من Firefox

---

### التخطيط مختلف في Safari

**المشكلة:** CSS يبدو مختلفاً في Safari

**الحلول:**
1. **أضف إصلاحات خاصة بـ Safari:**
   ```css
   /* خاص بـ Safari */
   @supports (-webkit-appearance: none) {
     /* CSS لـ Safari فقط */
   }
   ```
2. **تحقق من مشكلات iOS:**
   - متصفح Safari على الجوال قد يتصرف بشكل مختلف
   - اختبر على جهاز iOS فعلي إن أمكن

## الحصول على المساعدة

### قبل طلب المساعدة:

1. افحص رسالة الخطأ بعناية
2. ابحث على Google عن رسالة الخطأ
3. تحقق من Stack Overflow (مُعلَّم بالتقنية ذات الصلة)
4. راجع توثيق المشروع
5. جرّب مسح الذاكرة المؤقتة وإعادة التشغيل

### عند طلب المساعدة، اذكر:

- **رسالة الخطأ** (النص الدقيق)
- **خطوات إعادة الإنتاج** (ما الذي فعلته)
- **ما توقعته** (ما الذي يجب أن يحدث)
- **البيئة** (Windows/Mac، المتصفح، إصدار Node)
- **مقتطف الكود** (إذا كان مناسباً)
