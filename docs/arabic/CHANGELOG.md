## [1.2.0] - 2026-02-10

### تجديد رئيسي للبناء والمُعالجات 

استبدال ملفي لـ "compilepg.cjs" بأليات سير جديد باستخدام **Gulp**، بإضافة خواص تحميل الموقع لـ Firebase وتكامل المعالجات الخارجية 

#### أُضيف 

**نظام Gulp بالواجهة (`gulp.cjs`)**
- الـ Gulp 5.0.1 كمُشغل أستكشاف رئيسي 
- ألامر `app-js` المُكلف بمعالجات وتقليص وتصغير اكواد JS عبر معطيات "gulp-uglify" المُتجهه لـ  `public/dist/app.mjs`
- الـ `app-css` المُكلف بإدماج الــ CSS لــ `public/dist/css/app.css`
- أوامر `pug` تجميع اكواد ملفات القوالب إلى 4 حزم، على كل من اللغتين بنظاميها (المجموع 16 واجهه عرض) في مجلد `public/`
- مُعطيات الرقابة والمشاهدة الحيه `watch` في المجلدات التالية `src/assets/js/` , `src/assets/css/`, و `src/index.pug`
- المخرجات الأساسيه مُعتمده على نظام السلسلات المتصله `app-css ← app-js ← pug`
- الـ  `gulp-concat` (v2.6.1), `gulp-uglify` (v3.0.2), `gulp-pug` (v5.0.0), `gulp-preprocess` (v6.0.0)

**حزم واكواد (تحدثت بـ `package.json`)**
- `npm start` -  كود التشغيل الموازي للمعالجات الجذيرية (gulp, lint, deploy, babel)
- `npm run watch` - إملاء لـ  `gulp -f gulp.cjs watch`
- `npm run gulp` - إيقان مسارات عمليات الـ Gulp الكُلية
- `npm run babel` - تماثل تحويلي لملفات الـ Babel نحو مجلد `public/dist/`
- `npm run deploy` - مُخصص للربط بنظام الاستضافه الداخلي Firebase 
- الــ `npm run lint` / `npm run lint:fix` - لتمحيص اخطاء التدوينات لـ CSS وَ JS

**تصانيف تحويل Babel**
- إضافة كلاً من `@babel/cli` (v7.28.6)، `@babel/core` (v7.29.0)، `@babel/preset-env` (v7.29.0) 
- ملف `babel.config.json` - لدعم الـ core-js لمتطلبات وتيسيرات الخصائص الجديده
- دعم وتكامل `core-js` بإصداره 3.48.0 لخواص المعالجات التشغيلية الحديثة

**ربط الاستضافات في تقنيـه Firebase**
- تطبيق اِعتِماد الـ Firebase (12.9.0) 
- `firebase.json` – مُزود الاعداد للإستضافه ومسارات الـ `public/` المُستهدفة
- `.firebaserc` - الِإعْداد الخاص باِسم المشروع المُستعار
- دليـل ملفاته `.firebase/`

**أمــان وقدرات برمجيه**
- استخدام واجهة التطبيق المأمونة لـ `dompurify` بالإصدار 3.3.1 للتعقييم
- تطبيق إفتراضي لنمط المخرجات Server-side في DOM بإضافه `jsdom` باصداره 28.1.0 
- دعم مسارات ملف الـ البيئة (.env) المستتر بفضل واجهة `dotenv` المُعبئة في `gulp.cjs`
- مُحركات الـ (parallel npm script) لضمان العمليات والإخراج المتوازي `concurrently` (v9.2.1)

**أدوات المُعالجة**
- دعم مُطابقة النِطاق الُعالمي `globals` 17.2.0 بالإسلينت 
- تَكييف الواجهات وإتساق ملفات CSS بإدماج الـ `scss` 0.2.4
- إعداد المتتالية الجُزئيـه `gulp-sequence` بالإصدار الأول له 
- انواع النماذج في بيئة TypeScript:  `@types/jquery`, `@types/node`, `@types/pug`, `@types/core-js`
- إضافة الإقتراحات الجماليّة والكودية المٌمنهجة مسبقاً `.prettierrc`

**إعادة التشكيل والإخراج لمجلد الدلائل**
- مُحصلة ناتج تحويل واجهات عرض (HTML) تُحفظ بمحتويات الـ `public/` (تم تغييره من `dist/` المسبق إعداده)
- ملف `public/dist/` - الحزم الضبابية الخاصة بملفات الـ JS و CSS 
- ملف `public/assets/` - الملحقات والأصول الجماليّة المتصلبه، الخطوط الُمدمجه، والصور الفائقه 
- مجلد `public/vendor/` لمُلحقات الطرف الخارجـى الُمدمجة والمحتوية للوظائف المٌحالة للشبكات
- ملفات جزئيات مُعرضه في `public/views/` 

#### عُدِلَ
- حجب الملف الأول والُمثبت مسبقاً `compilepg.cjs`، وإدراج الـ `gulp.cjs`
- الحذف التدريجي لـ `nodemon` حيث أستوفته خصائص المراقبه الحيه `watch` في أداء عمل Gulp
- عزل تبعية المعالجات أثناء تشغيل الموجهات الخاصه بـ `pug` — وتم تسليط هذا الدور إلى مسارات الـ Gulp 
- حذف الحزم والإستدراكات المرتبطه بـ `owljs`, و `waypoints`, كـذالك `i18next` من نطاقات ملفات الـ `package.json`
- تحديث رقم الأصدار بالـ `package.json` لـ `1.2.0`

حلُّه شامله جاهزه مُهَيأة بالكامل لتطبيقات قالب عرض الـ HTML5 التابعة لاستشِعارات ومُقتضات التقييم المٌجَسده لوكالات التطوير، تحصيل الزيارات الخاصه بالباحثين، وباقات التوافق الُمثلى للترجمه. تمهيدًا لمنصات بيئات التطوير الإنتقائيه

**بناء التصميم والمحاور القياسية**
- الـ تمييز بالقوالب (Pug)  (`src/index.pug`) — كون المرجع الاسترشادي والمُحصل النهائي لواجهات الـ HTML 
- عدد الـ 16 سمه قالب (HTML) تم تجهيزه للواجهات التشغيلية والأنتاج 
  - اللغتان: الإنجليزية  (`en`) والعربية (`ar`) المُدعمة بدوال المٌحاذاة التلقائيه اليمينية (RTL support) .

  - الأوجه المتعددة للعرض بـ الدكان (Dark) وأيضا المُضيئ (Light)

## السِيَمــانتك فيرجينيج (النُسخ المُدَوْنه والمتأصّلہ للبرمُجيّات) 

التَنـسيق الدليلي:  `MAJOR.MINOR.PATCH`

- **MAJOR (الـحـَافِـز الرَئيِسيِ الخَاصّ)**: التّجـازوِزات والاِستِدلالَات الـجَذريِہ وَ الكـُبـرى (عـلى سبيل المثال تغيير مُحَاكى النظام وَتكيِف عمليّـة بناء التطبيِقات بكُلِيتِها) 
- **MINOR (الجـُزْء الـمـنخَـفضِ والأدنى)**: الخـواِص الأحدٌث والميزات الإضـَأفِيـہ، وبقـاء الإنسجآمـ مع البيئة الِاساسيه الٌمدرجہ والمؤخره 
- **PATCH (الِإسَـقَـاٹ الــمعقّد)**: التنَقُيـحات وإصلاَحات الخلل، أو عملِيات الإضِافة الخاصہ بالـُـتطويرَات الثَانَويہَ بالملفات.

- [ ] الدَلالآتِ والصُوّر والَخـِيارات النـموذجيِہ الخـاصہ بالألوان المُدمَجـہ والثييمَات (theme variations) المُزدوِجَہ 
- [ ] التَوثيِـفات المُخْتصہ بِمكتــبات وأقِسامـ المُلحقَـات (Component library) 
- [ ] ادماج الاستـقصاء الخِـاصّ، وَالتفَاعلياُـِت ذات التُـوَجْه الخَاص باِقٌسَـام الِمَـقاطِع الَفـيديو المتعددِه 
- [ ] التِكـأفـہ وَتوضِيع التَواقُـعات الخَاِصـہ بدمِج أجزاءِ تـَسـجيّل المٌشتركيـّن الخٌاصّ بِالإشعَأرات والبّريِد الأكترٌونـيّ (Newsletter)  
- [ ] إدراج المُزَاح السَّلِس (slider) الخاص بِالتأكيدات والتَعِقيّبات التابعت للٌعُمَلَاءِ ِ (Clients) 
- [ ] إِدِماج خَاصيـه العَرض والاستدلِالّات الُـمرئيہ لمُتشاركِي الٌفرِيق (Team members) 
- [ ] بَـلَــوره وإضافَة مَقطِع اسعَـاري مُخصصّ للتُوضِـيحات الخاصة بالقيمَ المعروضہ للِبيـّع 
- [ ] تَـتـوّيج الَصَفحَـات الإقسِامـ والمًَـقاطع الخاصه بِالتُوضيح للُمـداوّلة والدّلَالَات الخاصَہ بـ إدراجِ الْمُدونـات (Blog listing) 
- [ ] الْتفعيِــل التّأامٌ لوظائف وحالَـات آليّه الٌبَحث الاستعلامِيہ 
- [ ] إضافِة أنماط الإستدِلالَاتِ والأمٌثلَه التـوضيحيّـه للدمَج مع مُمـطَـيات وتَحِليّـلاّتـ زوارِ الموقِع Analytics integration 
- [ ] التأسِيس وإدراجـ نٌسخَــہ بِإعـتمآد React أو Next.js
