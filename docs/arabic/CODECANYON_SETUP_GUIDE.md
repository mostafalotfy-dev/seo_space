# SEO Space - دليل إعداد CodeCanyon

## معلومات ما قبل البيع

### ما يتضمنه الشراء
- ✓ قالب HTML5 كامل الوظائف
- ✓ 16 ملف HTML مُجمَّع مسبقاً (جميع توليفات السمات/اللغات)
- ✓ قالب Pug المصدري للتخصيص
- ✓ جميع المصادر (CSS، JavaScript، صور، خطوط)
- ✓ توثيق شامل
- ✓ دعم متعدد اللغات (إنجليزي وعربي)
- ✓ سمات ألوان متعددة
- ✓ تنويعات الوضع الداكن/الفاتح

### ما ستحصل عليه

1. **16 ملف HTML جاهز مسبقاً**
   - 2 لغات (إنجليزي، عربي)
   - 4 سمات (Ignite، Navy، Corporate Tech، Olive Garden)
   - 2 أوضاع (داكن، فاتح)
   - المجموع: 2 × 4 × 2 = 16 تنويع

2. **الكود المصدري الكامل**
   - قالب Pug (src/index.pug)
   - أوراق أنماط CSS
   - ملفات JavaScript
   - ملفات التوطين
   - ملفات الإعداد

3. **التوثيق الكامل**
   - 14+ دليل شامل
   - أمثلة كود
   - تعليمات التخصيص
   - نصائح استكشاف الأخطاء

## التثبيت والإعداد

### الطريقة 1: البداية السريعة (موصى بها لمعظم المستخدمين)

**لا تثبيت مطلوب! استخدم ملفات HTML الجاهزة مباشرةً**

1. **نزّل حزمة القالب**
2. **استخرج إلى المكان المطلوب**
3. **افتح أي ملف HTML في متصفحك**
4. **تم! القالب جاهز للاستخدام**

### الطريقة 2: مع Node.js (للتخصيص المتقدم)

**المتطلبات الأساسية:**
- Node.js v14+ مثبت
- npm v6+ (يأتي مع Node.js)

**الخطوات:**

```bash
# 1. استخراج حزمة القالب
# 2. فتح موجه الأوامر/الطرفية في مجلد القالب
# 3. تثبيت التبعيات
npm install

# 4. بدء المراقبة للتغييرات
npm run watch

# 5. تحرير ملفات src/index.pug، locals/، وsrc/assets/
# 6. ملفات HTML تُعاد التوليد تلقائياً

# 7. فتح HTML المُولَّد في المتصفح للمعاينة
```

### الطريقة 3: تعديل HTML مباشر (بدون معرفة برمجية)

1. **استخرج القالب**
2. **افتح ملف HTML بمحرر نصوص** (Notepad++، Sublime Text، VS Code)
3. **ابحث عن النص الذي تريد تغييره**
4. **حرّره مباشرةً في الملف**
5. **احفظ الملف**
6. **أعد تحميل المتصفح لرؤية التغييرات**

```

├── ملفات HTML (جاهزة للاستخدام)
```

## تحديث نموذج التواصل

### قبل استخدام نموذج التواصل

يحتاج النموذج تكاملاً خلفياً لإرسال الرسائل.

### الخيار 1: استخدام FormSubmit (مجاني، بدون إعداد)

1. **ابحث عن النموذج في HTML:**
```html
<form id="contact" action="" method="post">
```

2. **غيّر إلى:**
```html
<form id="contact" action="https://formsubmit.co/your@email.com" method="post">
```

3. **استبدل** `your@email.com` ببريدك الإلكتروني الفعلي
4. **احفظ واختبر** — الإرسال الأول سيرسل لك رابط التأكيد

### الخيار 2: استخدام Netlify Forms

1. **انشر على Netlify** (استضافة مجانية)
2. **Netlify يكتشف ويعالج النماذج تلقائياً**
3. **لا تغييرات كود** مطلوبة

### الخيار 3: خدمة خلفية

استخدم خدمات مثل:
- Formspree (formspree.io)
- Basin (usebasin.com)
- Getform (getform.io)

## تبديل السمات

### التبديل بين السمات

**الخيار 1: استخدم ملف HTML مختلف**
- افتح ببساطة ملف HTML مختلف
- لكل منها سمة مختلفة مُطبَّقة

**مثال:**
- تستخدم `output-en-theme-navy-dark.html` لسمة navy
- تريد التبديل إلى ignite؟ افتح `output-en-theme-ignite-dark.html` بدلاً منها

**الخيار 2: إضافة محوّل السمة (متقدم)**

أضف هذا الكود قبل إغلاق `</body>`:

```html
<script>
  function switchTheme(themeName) {
    const link = document.querySelector('link[href*="color-palette"]');
    link.href = `assets/css/color-palette/${themeName}.css`;
  }
  
  function switchMode(mode) {
    document.body.dataset.theme = mode;
  }
</script>

<div class="theme-switcher">
  <button onclick="switchTheme('navy')">نيفي</button>
  <button onclick="switchTheme('ignite')">إيغنايت</button>
  <button onclick="switchMode('dark')">داكن</button>
  <button onclick="switchMode('light')">فاتح</button>
</div>
```

أضف إلى `.htaccess` (خوادم Apache):

```apache
<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType image/jpeg "access plus 1 year"
  ExpiresByType image/png "access plus 1 year"
  ExpiresByType text/css "access plus 1 month"
  ExpiresByType application/javascript "access plus 1 month"
</IfModule>
```

## استكشاف الأخطاء

### المشكلة: الصور لا تظهر

**الحل:**
- تحقق من صحة مسارات ملفات الصور
- تأكد من وجود جميع الملفات في مجلد `src/assets/images/`
- تأكد من الحفاظ على هيكل المجلد

### المشكلة: الأنماط لا تُطبَّق

**الحل:**
- امسح ذاكرة التخزين المؤقت للمتصفح (Ctrl+Shift+Delete)
- تأكد من صحة مسار ملف CSS
- تحقق من امتداد الملف (.css)
- أعد تحميل الصفحة (Ctrl+F5)

### المشكلة: الروابط لا تعمل

**الحل:**
- استخدم المسارات النسبية: `assets/css/main.css`
- لا تستخدم المسارات المطلقة: `C:/Users/...`
- تأكد من تطابق أسماء الملفات بدقة
- تحقق من الأخطاء المطبعية في سمات href

### المشكلة: النموذج لا يُرسَل

**الحل:**
- تأكد من صحة سمة `action` في النموذج
- تحقق من إعداد خدمة البريد الإلكتروني
- افتح وحدة تحكم المتصفح (F12) للتحقق من الأخطاء
- اختبر بتنسيق بريد إلكتروني صالح

### المشكلة: القالب يبدو مختلفاً على جهازي

**الحل:**
- امسح ذاكرة التخزين المؤقت للمتصفح
- جرّب متصفحاً مختلفاً
- تحقق من العرض المتجاوب (F12 ← شريط الأجهزة)
- تأكد من تحميل جميع المصادر بنجاح
