# توثيق لوحة الألوان

## نظرة عامة

يتضمن SEO Space خمس لوحات ألوان مصممة باحترافية مع دعم كامل لوضعي الداكن/الفاتح. كل سمة مُعرَّفة في ملف CSS منفصل يحتوي على خصائص CSS المخصصة (المتغيرات) لتسهيل التخصيص.

## ملفات السمات

| السمة | الملف | الاستخدام |
|-------|-------|----------------|
| **Loyal Green** | `assets/css/color-palette/loyal-green.css` | علامة تجارية خضراء راقية واحترافية |
| **Navy** | `assets/css/color-palette/navy.css` | مهني واحترافي للشركات |
| **New Corporate Tech** | `assets/css/color-palette/new-corporate-tech.css` | شركة تقنية حديثة |
| **Olive Garden Feast** | `assets/css/color-palette/olive-garden-feast.css` | علامة طبيعية، ترابية وعضوية |
| **Cranberries** | `assets/css/color-palette/cranberries.css` | علامة دافئة مستوحاة من التوت |

## نظام متغيرات الألوان

### المرجع الكامل للمتغيرات

جميع السمات تعرّف هذه الخصائص المخصصة لـ CSS، مرتبة حسب الفئة:

```css
:root {
  /* ========================
     ألوان الخلفية الأساسية
     ======================== */
  --main-color              /* الخلفية الأساسية لمحتوى الصفحة الرئيسي */
  --secondary-color         /* خلفية الأقسام والبطاقات والمكونات */
  --light-bg-color          /* خلفية فاتحة/ناعمة للعناصر المتداخلة */
  
  /* ========================
     ألوان العلامة التجارية والتمييز
     ======================== */
  --third-color             /* لون العلامة التجارية الأساسي للروابط والأيقونات */
  --accent-color            /* لون التمييز لأزرار CTA والعناصر التفاعلية */
  --secondary-hover-color   /* حالة التحويم (hover) للعناصر التفاعلية الثانوية */
  
  /* ========================
     ألوان النصوص
     ======================== */
  --text-color              /* لون النص الأساسي لمحتوى الجسم */
  --title-color             /* لون العناوين والرؤوس */
  --paragraph-color         /* لون نص الفقرات */
  --text-muted              /* نص باهت/ثانوي للمعلومات الأقل أهمية */
  --text-hover-color        /* لون النص عند التحويم */
  --text-accent-color       /* لون النص المميز للتركيز */
  --heading-color           /* لون العناوين العامة */
  --history-text-color      /* لون نصوص السجل/الجدول الزمني */
  
  /* ========================
     الألوان المساعدة (Utility)
     ======================== */
  --light-color             /* لون فاتح مساعد */
  --dark-color              /* لون داكن مساعد */
  --selection-color         /* لون تمييز تحديد النص */
  --header-bg-color         /* لون خلفية الترويسة (Header) */
  
  /* ========================
     التنقل والقوائم
     ======================== */
  --navbar-list-color       /* لون عناصر قائمة التنقل */
  --list-color              /* لون عناصر القوائم العامة */
  --footer-text-color       /* لون نص التذييل (Footer) */
  
  /* ========================
     الطباعة (Typography)
     ======================== */
  --font-family             /* مجموعة الخطوط الأساسية للسمة */
  --text-muted-placeholder  /* لون النص النائب (Placeholder) لحقول الإدخال */
  
  /* ========================
     ألوان وسائل التواصل الاجتماعي
     ======================== */
  --linkedin-hover-color    /* لون التحويم الخاص بعلامة LinkedIn */
  --facebook-hover-color    /* لون التحويم الخاص بعلامة Facebook */
  --twitter-hover-color     /* لون التحويم الخاص بعلامة Twitter */
  --instagram-hover-color   /* لون التحويم الخاص بعلامة Instagram */
  --youtube-hover-color     /* لون التحويم الخاص بعلامة YouTube */
  
  /* ========================
     ألوان حالة التعطيل (Disabled)
     ======================== */
  --disabled-color          /* خلفية العناصر المعطلة */
  --disabled-hover-color    /* حالة التحويم للعناصر المعطلة */
  --disabled-text-color     /* لون نص العناصر المعطلة */
  
  /* ========================
     تدرجات الرمادي
     ======================== */
  --gray-color              /* لون رمادي قياسي */
  --gray-hover-color        /* لون الرمادي عند التحويم */
}
```

## استخدام السمات

### اختيار سمة

أثناء التطوير أو التجميع، حدد اسم السمة في ملف البيئة `.env`:

```env
THEME=olive-garden-feast  # أو 'navy', 'ignite', 'new-corporate-tech', 'cranberries', 'loyal-green'
```

### في إخراج HTML

يتم استدعاء السمة في واجهة الاستخدام من خلال ملف التنسيق (stylesheet):

```html
<link rel="stylesheet" href="assets/css/color-palette/olive-garden-feast.css">
```

### تبديل السمات بـ JavaScript

```javascript
// تغيير الوضع المظلم/الفاتح في وقت التشغيل
document.body.dataset.theme = 'dark'; // أو 'light'

// تغيير لوحة الألوان (يتطلب تغيير ورقة أنماط CSS)
const link = document.querySelector('link[href*="color-palette"]');
link.href = 'assets/css/color-palette/navy.css';
```

## نظرية الألوان وأفضل الممارسات

### متطلبات التباين اللوني

- **نص المحتوى على الخلفية المقابلة**: نسبة تباين 4.5:1 كحد أدنى متطلب لـ (WCAG AA)
- **العناوين الرئيسية**: نسبة تباين 3:1 كحد أدنى
- **العناصر التفاعلية للمواقع**: تمييز بصري لجميع المتغيرات الوظيفية والعضلية.

### توليفات الألوان الموصى بها

#### الوضع الداكن
```
الخلفية:        داكنة وعميقة جداً (#000 إلى #1a)
النص:           رمادي فاتح/أبيض ناعم (#e إلى #f)
اللون الأساسي:  ألوان ساطعة (بدرجات تشبّع عالية ومبهجة)
اللون الثانوي:  درجات ألوان داعمة مكمّلة باعتدال
```

#### الوضع الفاتح
```
الخلفية:      ألوان بيضاء/كريمية ناعمة (#f إلى #fff)
النص:         رمادي داكن/أسود واضح (#0 إلى #2)
اللون الأساسي: لون مبهج ومميز بـ تشبّع متوسط
اللون الثانوي: لون مساند هادئ وداعم للتركيز الأساسي
```

## اعتبارات إمكانية الوصول و دعم الإرشادات الطبية للمُستَخدِمين

### عمى الألوان 
- لا تعتمد على اللون وحده وحصرياً لنقل المعلومات وبيئة الاستخدام الخاصة بالوظائف .
- استخدم الأنماط، العلامات، الأيقونات، والتنبيهات، إضافةً إلى التسميات النصية الداعمة والتوضيح البنيوي. 
- اختبر الألوان وألواح المجموعات عبر مراجع أدوات إمكانية الوصول . 

### وضع التباين العالي والمتوسط
- يتم تكييف المٌتغيرات المٌعَرفة تلقائياً بِناءً على وضع عرض الاستخدام.
- تتيح اللوحات الفاتحة توفير نسبة تباين عالي كخيار دائم وافتراضي.
- السمة المظلمة والمخصصة توفر التباينات والانعكاسات المتضادة (inverted contrast) الواضحة والصريحة.

### الحركة، المٌوثرات الإنتقالية و الأنمَيِشِن   
- ضرورة الالتزام والمراعاة للقوانين والقيود المعينة لدرجات المتطلب `prefers-reduced-motion` 
- إختبار تجارب وقياس فاعليه الأنميشن بالربط مع معايير الـ (accessibility checker).

## اختبار السمات واللوجًو البصري

### أدوات DevTools للمتصفحات المُصاحبة 

```javascript
// قياس واختبار نفاذ الـ CSS للمتغير اللوني في اللوحة الرئيسية
getComputedStyle(document.body).getPropertyValue('--main-color')

// طريقة تغيير وتبديل الأنماط والسمات برمجيًا في أوامر الأستعراض 
document.body.dataset.theme = 'light';
```

### قائمة الفحص والتأكيد لمُختبري الجودة 

- [ ] كافة المحتويات والمحتويات النصية قابلة للقراءة بشكل ممتاز (نسبة التباعد والتباين لا تقل عن 4.5:1)
- [ ] الإرتباطات النصية والروابط مميزة بوضوح 
- [ ] الـمُرْئِيَات وحالات الاستجابة عند التمرير (Hover states) مرئية للعين 
- [ ] إشـتعار حالات الاستهداف والتركيز (Focus states) مستساغة وتميزية بوضوح
- [ ] الوضوح التام وعدم التعارض في الوضع والمجال المظلم
- [ ] الإستقرار التام في الألوان في المجال الصريح والمُضِيء (الفاتح)

- [ ] تحميل وإظهار الصور بطريقة واضحة ومكملة ولا تتقاطع بصرياً مع درجة السمـات الرئيسية المُطبقه.

## استكشاف الأخطاء الشائعة وإصلاحها المستمر

### مشكلة: تعطل الألوان والأكواد أو عدم انعكاسها
- تحقق أن ملف الـ CSS المخصص تم تحميله وادراجه دون أخطاء (راجع نافذة الفحص الـ network بمتصفحك)
- مسح أو تنظيف ذاكرة التخزين المؤقتة المُرتبطة بالمتصفح بشكل دوري.
- تحقق من مستويات التأثير المباشر لمرجعيات الـ (CSS Specificity) الخاصه للمتغيرات في أكوادك.

### مشكلة: السمة المُرتبطة بالـ (Theme) عالقة أو تالفة ולא تتجاوب للتتغيير والتألق
- تحقق من توافر سمة القيمة والمكون المخصص بالكلمة الـ `data-theme` بداخل العنصر `<body />` 
- تأكد أن الدالة الُمعَرِّفة الخاصة بالنموذج والموضحة بالعمل والدمج (الداكن/الفاتح) تعمل بالشكل السليم وبمستواها المخصص 
- اختبر وظيفة الٌتبديل البرمجية للسمة عن طريق بيئة المطورين: `document.body.dataset.theme = 'dark'` أو `light` .

### مشكلة: نسبة التباين ضعيفة جداً או غير قابلة للمشاهدة
- أضف الاستعانة والإستعانة الفورية بخبرات مرجع فحص الـ إمكانية والتباين كـ (אקס Axe، ו-و WAVE)
- حسّن قيمة ونسب الإمتصاص والتشبّع المتباينة بالألوان (color saturation) بالمعقول.
- أجرِى تعديلات وتصليحات متكررة على نسب التألق والسطوع التبايني الخاص بالمٌدرجات والمُتغيرَات (brightness values).
