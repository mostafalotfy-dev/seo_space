# SEO Space - توثيق المشروع

> قالب HTML5 احترافي لوكالات التسويق الرقمي وخدمات تحسين محركات البحث

## نظرة عامة

SEO Space قالب حديث وسريع الاستجابة ومصمم باحترافية لوكالات التسويق الرقمي ومزودي خدمات SEO. تم بناؤه باستخدام **قوالب Pug** و**Bootstrap 5** و**تكامل Firebase** و**توطين i18next**، ويوفر حلاً شاملاً جاهزاً للإنتاج لعرض خدمات SEO، وقدرات التسويق الرقمي، ومصادقة المستخدمين.

يأتي القالب مع 16+ ملف HTML مُجمَّعاً مسبقاً يدعم لغتين (الإنجليزية والعربية)، و 5 سمات ألوان احترافية، ووضعين للعرض (داكن وفاتح)، وصفحات مصادقة كاملة.

## دليل البدء السريع

### المتطلبات الأساسية
- **Node.js** v14.0.0 أو أعلى ([تنزيل](https://nodejs.org/))
- **npm** v6.0.0 أو أعلى (يأتي مع Node.js)
- **محرر أكواد** (يُنصح بـ VS Code)
- **ذاكرة RAM لا تقل عن 2 جيجابايت**، ~500 ميجابايت مساحة قرص

### خطوات التثبيت

```bash
# 1. الانتقال إلى مجلد المشروع
cd d:\projects\seo_Space

# 2. تثبيت التبعيات (2-5 دقائق)
npm install

# 3. تشغيل وضع التطوير مع إعادة التجميع التلقائية
npm run watch

# أو تجميع مرة واحدة بدون مراقبة
npm run watch:gulp
```

## السكربتات وأوامر البناء

### أوامر NPM المتاحة

```bash
# التطوير
npm start              # تشغيل الكل:
                       # - مراقبة Gulp (القوالب)
                       # - مراقبة Rollup (تجميع JS)
                       # - Linter (جودة الكود)
                       # - Babel (تحويل الكود للعرض الجيد)
                       # - نشر Firebase

# مراقبة التغييرات
npm run watch:gulp     # مراقبة وتجميع قوالب Pug ← /public
npm run watch:rollup   # مراقبة وتجميع JavaScript ← /public/dist/

# بناء لمرة واحدة
npm run gulp           # تجميع قوالب Pug لمرة واحدة
npm run babel          # تحويل ES6+ ← كود JS متوافق مع ES5
npm run lint           # التحقق من جودة الكود باستخدام ESLint
npm run lint:fix       # الإصلاح التلقائي لمشكلات ESLint

# النشر
npm run deploy         # النشر إلى Firebase Hosting
```

### كيف يعمل نظام البناء

**تتابع الأدوات المتعددة:**

1. **Gulp** (`gulp.cjs`)
   - يراقب تغيرات مجلد `/src`
   - يجمع قوالب Pug ← HTML
   - يدمج ملفات CSS
   - يخرج إلى `/public`
   
   ```bash
   npm run watch:gulp    # إعادة تجميع تلقائية عند الحفظ
   ```

2. **Rollup** (`rollup.config.mjs`)
   - يراقب ملفات JavaScript
   - يجمّع وتزيل الأكواد غير المستخدمة (tree-shakes)
   - يخرج إلى `/public/dist`
   
   ```bash
   npm run watch:rollup  # تجميع تلقائي عند الحفظ
   ```

3. **Babel** (`babel.config.json`)
   - يُحوِّل ES6+ ← ES5
   - يضمن التوافق مع المتصفحات
   
   ```bash
   npm run babel         # يُشغل لمرة واحدة أو يُراقب كما في الأعلى
   ```

4. **ESLint** (`eslint.config.mjs`)
   - يتحقق من جودة الكود
   - يمسك بالأخطاء الشائعة
   
   ```bash
   npm run lint          # للتحقق
   npm run lint:fix      # للإصلاح التلقائي
   ```

## المهام الشائعة

### تغيير السمة
عدّل متغير `theme_name` في عملية التجميع أو حدّث خاصية `data-theme`.

### إضافة قسم جديد
1. أنشئ mixin جديد لـ Pug في `index.pug`
2. أضف الترجمات إلى `locals/en.json` و`locals/ar.json`
3. أضف الأنماط إلى `assets/css/main.css`
4. أعد التجميع باستخدام `npm run watch:gulp`

### تبديل اللغة
حدث متغير اللغة قبل التجميع أو استخدم مبدّل لغات ديناميكي في جافا سكريبت.

### تخصيص الألوان
عدّل متغيرات CSS في `assets/css/color-palette/theme-name.css`

## استكشاف الأخطاء وإصلاحها

- **عدم تجميع القوالب**: تأكد من تكوين `gulp.cjs`، شغل `npm run gulp`، تحقق من إصدار Node.js
- **عدم تطبيق الأنماط**: امسح ذاكرة التخزين المؤقت للمتصفح، تأكد من مسارات ملف CSS
- **الترجمات المفقودة**: تحقق من ملفات JSON في مسار `locals/` لضمان وجود المفاتيح الصحيحة
- **عدم عمل التحريكات**: تأكد من تحميل `assets/js/animation.js`
