# المرجع السريع

## أوامر شائعة

```
npm install
npm run watch
npm start
npx eslint .
```

## مهام سريعة

- تغيير نص: عدّل `locals/en.json` و`locals/ar.json` أو `index.pug`
- تغيير الألوان: عدّل ملفات `assets/css/color-palette/*.css`
- إضافة قسم: أضفه في `index.pug` وأضف الترجمات والأنماط ثم أعد التجميع
