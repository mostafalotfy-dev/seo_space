# دليل SEO Nexus (العربية)

نظرة عامة

SEO Nexus قالب HTML5 احترافي مخصص لوكالات التسويق الرقمي وخدمات تحسين محركات البحث. يدعم القالب لغتين (الإنجليزية والعربية) وأربع سمات ألوان بالإضافة إلى وضعين (داكن/فاتح).

ميزات رئيسية

- دعم RTL للعربية
- قوالب Pug قابلة للتخصيص
- تجميع تلقائي لإنتاج ملفات HTML متعددة (لغة/ثيم/وضع)
- توثيق شامل لتسهيل التخصيص والنشر

بدء سريع

1. تثبيت التبعيات: `npm install`
2. تشغيل المراقبة: `npm run watch`
3. فتح ملفات HTML المولدة في المتصفح

راجع الملفات داخل مجلد `docs/` لمزيد من التفاصيل المتعمقة حول الإعداد والتطوير والنشر.
