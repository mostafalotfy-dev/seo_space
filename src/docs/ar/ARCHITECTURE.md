# بنية المشروع

## نظرة عامة

يعتمد المشروع على بنية مكونية مع قوالب Pug، وملفات CSS/JS منظمة. عملية البناء تنتج ملفات HTML متعددة حسب اللغة والثيم والوضع (داكن/فاتح).

## مجلدات رئيسية

- `index.pug` - القالب الرئيسي
- `assets/` - ملفات `css`, `js`, `images`, `fonts`
- `vendor/` - مكتبات الطرف الثالث (Bootstrap, jQuery)
- `locals/` - ملفات الترجمة (`en.json`, `ar.json`)

## سير التجميع

1. تعديل المصادر (Pug/CSS/JSON)
2. تشغيل `compilepg.cjs` (أو `npm run watch`)
3. إنشاء ملفات HTML للمجموعة (لغة × ثيم × وضع)

## دعم RTL

عند `lang === 'ar'` يتم ضبط `dir="rtl"` على `body`، ويتم تطبيق أنماط مناسبة لدعم اتجاه النص من اليمين لليسار.
