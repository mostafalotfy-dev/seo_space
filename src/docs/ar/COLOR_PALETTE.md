# دليل لوحات الألوان

SEO Nexus يحتوي على أربع لوحات ألوان احترافية مع دعم للوضع الداكن/الفاتح. تحدد كل لوحة متغيرات CSS (`--variables`) لتسهيل التخصيص.

## مواقع الملفات

- `assets/css/color-palette/Ignite.css`
- `assets/css/color-palette/navy.css`
- `assets/css/color-palette/new-corporate-tech.css`
- `assets/css/color-palette/olive-garden-feast.css`

## كيفية إنشاء ثيم جديد

1. أنشئ ملف CSS جديد في `assets/css/color-palette/` مع متغيرات `:root` للوضع الداكن وكتلة `@media` للوضع الفاتح.
2. أضف الثيم إلى إعدادات `compilepg.cjs` ثم أعد التجميع.

رموز وأمثلة المتغيرات تظل كما هي في الملفات الأصلية.
