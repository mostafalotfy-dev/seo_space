# SEO Space — الأسئلة الشائعة

## أسئلة عامة

### ما هو SEO Space؟
SEO Space قالب HTML5 احترافي مصمم لوكالات التسويق الرقمي ومزودي خدمات SEO. يتميز بتصميم عصري وسمات متعددة ودعم متعدد اللغات وجميع الأقسام اللازمة لعرض خدمات التسويق الرقمي.

### ماذا يشمل القالب؟
- 16 ملف HTML مُجمَّع مسبقاً (جميع توليفات السمات/اللغات)
- قالب Pug المصدري للتخصيص
- أوراق أنماط CSS كاملة
- ملفات JavaScript والمكتبات
- ملفات الترجمة (الإنجليزية والعربية)
- دعم التوطين
- توثيق عالي الجودة
- جميع الملفات (صور، خطوط، إلخ)

### هل أحتاج إلى مهارات برمجة؟
لا! يعمل القالب مباشرةً دون إعداد. يمكنك:
- استخدام ملفات HTML الجاهزة مباشرةً
- التحرير بأي محرر نصوص (Notepad، VS Code، إلخ)
- تغيير النصوص والصور والألوان بسهولة
- التخصيص دون معرفة برمجية

### هل هذا قالب WordPress؟
لا، هذا قالب HTML5 نقي. لا يتطلب WordPress أو أي نظام إدارة محتوى. انشره على أي استضافة ويب.

### هل يمكن استخدامه للمشاريع التجارية؟
نعم! يمكنك تخصيصه واستخدامه للعملاء وفق شروط الترخيص. مثالي للوكالات!

## أسئلة تقنية

### ما المتصفحات التي يدعمها؟
- Chrome (آخر إصدارين)
- Firefox (آخر إصدارين)
- Safari (آخر إصدارين)
- Edge (آخر إصدارين)
- Opera (آخر إصدارين)
- دعم محدود لـ IE 11

### هل هو متوافق مع الجوال؟
نعم! تجاوب كامل. يعمل بشكل مثالي على:
- سطح المكتب (1920px+)
- اللابتوب (1366px - 1920px)
- الأجهزة اللوحية (768px - 1024px)
- الجوال (320px - 767px)

### ما حجم الملفات؟
حوالي 2-5 ميجابايت إجمالاً (حسب الصور). خفيف جداً!

### هل أحتاج إلى Node.js أو npm؟
لا! ملفات HTML الجاهزة تعمل دون أي أدوات. Node.js/npm مطلوبان فقط إذا أردت تعديل قالب Pug.

### هل يعمل على استضافة مشتركة؟
نعم! يعمل على أي استضافة ويب قياسية:
- Apache
- Nginx
- IIS
- أي مزود استضافة

### ما سرعة تحميل الصفحة؟
سريع جداً! مُحسَّن بـ:
- CSS/JS مُصغَّرة
- صور مُحسَّنة
- Bootstrap جاهز للـ CDN
- دعم التحميل الكسول

### هل أحتاج إلى قاعدة بيانات؟
لا! HTML/CSS/JS نقي. لا قاعدة بيانات مطلوبة. لا خلفية مطلوبة.

### هل هو متوافق مع GDPR؟
هيكل القالب يدعم الامتثال لـ GDPR. تأكد من تطبيق سياسة الخصوصية وموافقة ملفات تعريف الارتباط (الكوكيز) بشكل صحيح.

## أسئلة التخصيص

### كيف أغير الشعار؟
**الخيار 1 (سهل):** استبدال ملف الصورة
1. جهّز صورة شعارك
2. احفظها في `assets/images/`
3. تعديل مسار الصورة في ملف HTML

**الخيار 2 (نص):** تعديل نص الشعار
1. ابحث في HTML: `<span>Dyna</span>`
2. غيّره إلى نصك: `<span>علامتك التجارية</span>`

### كيف أغير الألوان؟
1. افتح `assets/css/color-palette/navy.css`
2. ابحث عن متغيرات CSS في الأعلى: `--main-color: #003f87;`
3. غيّر قيم hex إلى الألوان المطلوبة
4. احفظ وأعد تحميل المتصفح

### كيف أضيف صوري الخاصة؟
1. احفظ الصور في مجلد `assets/images/`
2. ابحث عن الصورة في HTML: `<img src="assets/images/banner.png">`
3. غيّر اسم الملف إلى اسم صورتك
4. احفظ وأعد تحميل المتصفح

### كيف أغير المحتوى النصي؟
1. افتح ملف HTML بأي محرر نصوص
2. ابحث عن النص المراد تغييره
3. حرّره مباشرةً
4. احفظ الملف
5. أعد تحميل المتصفح

### هل يمكن إضافة صفحات جديدة؟
نعم! خيارات متعددة:
1. انسخ ملف HTML وعدّله
2. أنشئ ملف HTML جديداً بنفس مجلد الملفات
3. أضف أقساماً جديدة إلى الصفحة الحالية

### كيف أبدّل السمات؟
ببساطة استخدم ملف HTML مختلفاً:
- `output-en-theme-navy-dark.html` للسمة navy
- `output-en-theme-ignite-dark.html` للسمة ignite
- `output-en-theme-new-corporate-tech-dark.html` للسمة tech
- `output-en-theme-olive-garden-feast-dark.html` للسمة olive

### هل يمكن إنشاء سمة مخصصة؟
نعم! للمستخدمين المتقدمين:
1. أنشئ ملف CSS جديداً في `assets/css/color-palette/`
2. عرّف متغيرات الألوان
3. أضف السمة إلى مصفوفة `themes` في `gulp.cjs`
4. اختبر وانشر

راجع [COLOR_PALETTE.md](COLOR_PALETTE.md) للدليل التفصيلي.

### كيف أضيف لغات أخرى؟
للمستخدمين المتقدمين مع إعداد Pug:
1. أنشئ ملف الترجمة `locals/new-lang.json`
2. ترجم جميع النصوص
3. حدّث سكريبت التجميع `gulp.cjs`
4. أعد توليد ملفات HTML

راجع [LOCALIZATION.md](LOCALIZATION.md) للدليل التفصيلي.

### كيف أعدّل النموذج؟
1. ابحث عن النموذج في HTML: `<form id="contact">`
2. عدّل حقول الإدخال
3. أضف action لإرسال البريد الإلكتروني
4. اختبر إرسال النموذج

### هل يمكن حذف أقسام؟
نعم! الأقسام معيارية:
1. ابحث عن القسم في HTML (مثل `<section id="services">`)
2. احذف القسم بالكامل
3. احفظ واختبر

### كيف أضيف تحريكات؟
التحريكات جاهزة للاستخدام! أضف إلى أي عنصر:
```html
<div class="wow fadeInUp" data-wow-duration="1s">
  محتواك
</div>
```

التحريكات المتاحة: fadeIn, slideIn, bounceIn, zoomIn، إلخ.

## أسئلة النشر

### كيف أرفع الملفات إلى الاستضافة؟
**الطريقة 1: FTP**
1. نزّل عميل FTP (FileZilla)
2. اتصل ببيانات الاستضافة
3. ارفع جميع الملفات إلى public_html
4. حافظ على هيكل المجلدات

**الطريقة 2: Firebase (مُدمَج)**
```bash
npm run deploy
# أو
npm start  # يبني وينشر دفعة واحدة
```

**الطريقة 3: Git (Netlify/Vercel)**
1. ادفع إلى GitHub
2. اربط منصة الاستضافة
3. نشر تلقائي عند كل دفعة

### ما الاستضافة التي أحتاجها؟
أي استضافة ويب قياسية:
- Bluehost، GoDaddy، Hostinger، SiteGround، HostGator
- أو Firebase Hosting (مُدمَج في المشروع)

**الحد الأدنى من المتطلبات:**
- خادم ويب (Apache/Nginx)
- دعم HTML (متوفر في كل مكان)

### هل الاستضافة المجانية ممكنة؟
نعم! خيارات:
- **Firebase Hosting** (مجاني — مُدمَج في المشروع)
- Netlify (مستوى مجاني)
- Vercel (مستوى مجاني)
- GitHub Pages (مجاني)

### كيف أضبط نطاقاً مخصصاً؟
1. سجّل النطاق (GoDaddy، Namecheap، إلخ)
2. وجّه DNS النطاق إلى الاستضافة
3. حدّث خوادم الأسماء (Nameservers)
4. انتظر 24 ساعة للانتشار
5. الوصول عبر نطاقك المخصص

### كيف أفعّل HTTPS/SSL؟
معظم الاستضافات تتضمن SSL مجاناً:
1. لوحة التحكم ← شهادة SSL
2. فعّل التجديد التلقائي
3. تم! HTTPS مفعّل

## أسئلة النموذج والبريد الإلكتروني

### كيف أجعل نموذج التواصل يعمل؟
**الخيار 1: FormSubmit (الأسهل)**
1. غيّر action النموذج: `action="https://formsubmit.co/your@email.com"`
2. بدّل البريد الإلكتروني بعنوانك
3. احفظ
4. اختبر — ستحصل على رابط تأكيد
5. تم!

**الخيار 2: Formspree**
1. قم بزيارة formspree.io
2. أنشئ حساباً
3. احصل على معرف النموذج
4. حدّث عنوان action
5. تبدأ النماذج بالعمل

**الخيار 3: Netlify**
1. انشر على Netlify
2. أضف سمة netlify إلى النموذج
3. تتم معالجة النماذج تلقائياً

### هل يمكن الاتصال بنظام CRM؟
نعم! للتكامل المتقدم:
1. استخدم Zapier لربط النماذج بـ CRM
2. أو استخدم webhook نموذج الـ CRM
3. أو تكامل خلفية مخصص

## استكشاف الأخطاء

### الصور لا تظهر؟
- تحقق من صحة مسار الملف
- تأكد من وجود الصورة في `assets/images/`
- تأكد من صحة اسم الملف
- جرّب الإعادة القسرية (Ctrl+F5)

### الأنماط لا تعمل؟
- امسح ذاكرة التخزين المؤقت للمتصفح
- تحقق من مسار ملف CSS
- تحقق من وجود الملف
- أعد تحميل الصفحة بالكامل

### النموذج لا يُرسَل؟
- تحقق من صحة عنوان URL للـ action
- تأكد من إعداد خدمة البريد الإلكتروني
- تحقق من وحدة التحكم في المتصفح للأخطاء
- اختبر بتنسيق بريد إلكتروني صالح

### قائمة الجوال لا تعمل؟
- تأكد من تحميل Bootstrap JS
- تحقق من ربط معالجات النقر
- جرّب متصفحاً مختلفاً
- تحقق من وجود عنصر القائمة

### السمة لا تتغير؟
- تأكد من تحميل ملف CSS
- تحقق من تعريف متغيرات الألوان
- امسح ذاكرة التخزين المؤقت للمتصفح
- أعد تحميل الصفحة (Ctrl+F5)
