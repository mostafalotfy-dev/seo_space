# SEO Space - توثيق منتج CodeCanyon

## نظرة عامة على المنتج

**SEO Space** هو قالب HTML5 احترافي ومتجاوب مُصمَّم لوكالات التسويق الرقمي ومزودي خدمات تحسين محركات البحث. مبني بتقنيات حديثة تشمل Pug templating وBootstrap 5 ودعم شامل متعدد اللغات، يوفر هذا القالب كل ما تحتاجه لعرض خدمات تحسين محركات البحث وقدرات التسويق الرقمي.

### أبرز الميزات

✨ **تصميم احترافي** — واجهة عصرية ونظيفة مثالية للوكالات
🌍 **متعدد اللغات** — الإنجليزية والعربية مع دعم RTL
🎨 **4 سمات جميلة** — Ignite، Navy، Corporate Tech، Olive Garden Feast
🌓 **الوضع الداكن/الفاتح** — تبديل كامل للسمة
📱 **متجاوب بالكامل** — يعمل بشكل مثالي على جميع الأجهزة
⚡ **تحريكات سلسة** — تحريكات WOW.js عند التمرير
🔧 **سهل التخصيص** — كود منظم ومُعلَّق جيداً
📊 **قسم المعرض** — عرض المشاريع المُنجزة
📝 **نموذج التواصل** — وظيفة تواصل جاهزة للتكامل
🚀 **أداء مُحسَّن** — تحميل سريع، موارد مُحسَّنة

## ما يتضمنه المنتج

### ملفات القالب
- `src/index.pug` — القالب الرئيسي (يُجمَّع لعدة تنويعات HTML)
- ملفات HTML مُجمَّعة مسبقاً لجميع توليفات اللغة/السمة

## البدء السريع

### للمستخدمين النهائيين (لا يلزم برمجة)

1. **نزّل القالب**
2. **استخرج جميع الملفات**
3. **افتح أي ملف HTML** في متصفحك
4. **خصّص باستخدام محرر الكود** (VS Code، Sublime Text، إلخ)
5. **ارفع إلى استضافتك**

### للمطورين

1. **نزّل واستخرج**
2. **ثبّت Node.js** (إذا لم يكن مثبتاً)
3. **افتح الطرفية/موجه الأوامر**
4. **شغّل**: `npm install`
5. **شغّل**: `npm run watch`
6. **حرّر** `src/index.pug` و`locals/` و`src/assets/`
7. **ملفات HTML تتولد تلقائياً**

## خيارات التخصيص

### التخصيصات البسيطة (بدون برمجة)

1. **تغيير النص** — حرّر ملفات HTML مباشرةً أو استخدم ملفات الترجمة
2. **تغيير الألوان** — عدّل قيم ألوان CSS
3. **تغيير الصور** — استبدل ملفات الصور في `src/assets/images/`
4. **تغيير الخطوط** — حدّث روابط الخطوط في HTML
5. **إضافة/حذف الأقسام** — انسخ وعدّل كتل HTML

### التخصيصات المتقدمة (مع برمجة)

1. **تعديل القالب** — حرّر `src/index.pug` لتغييرات الهيكل
2. **إضافة لغات** — أضف ملفات ترجمة جديدة
3. **إنشاء السمات** — أضف لوحات ألوان CSS جديدة
4. **مكونات مخصصة** — أضف مكونات JavaScript
5. **تكامل النماذج** — اتصل بخدمات البريد الإلكتروني
