# دليل النشر (Deployment)

## نظرة سريعة

القالب ثابت (static) ويمكن نشره على أي استضافة تدعم ملفات HTML. لا يتطلب معالجة خادمية.

## طرق النشر الشائعة

- FTP إلى استضافة تقليدية (public_html)
- GitHub Pages
- Netlify (موصى به)
- Vercel
- AWS S3 + CloudFront

## خطوات عامة

1. تأكد من توليد ملفات HTML (`npm start`)
2. انسخ ملفات `output-*.html` ومجلد `assets/` و`vendor/` إلى الخادم
3. اختبر الموقع وتحقق من تحميل جميع الموارد
