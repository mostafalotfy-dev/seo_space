## [1.2.0] - 2026-02-10

### إعادة هيكلة نظام البناء بالكامل

- **Gulp** (v5.0.1) كمشغّل مهام رئيسي بدلاً من `compilepg.cjs`
  - مهمة `app-js` — دمج وتصغير JavaScript
  - مهمة `app-css` — دمج CSS
  - مهمة `pug` — تجميع 16 ملف HTML (4 سمات × لغتان × وضعان)
  - مهمة `watch` — مراقبة الملفات وإعادة البناء تلقائياً
- **Firebase Hosting** — نشر تلقائي عبر `npm run deploy`
- **Babel** — تحويل JavaScript الحديث عبر `@babel/preset-env` و`core-js`
- تبعيات جديدة: `dompurify`، `dotenv`، `jsdom`، `concurrently`، `globals`، `prettier`
- تعريفات TypeScript: `@types/jquery`، `@types/node`، `@types/pug`
- مجلد الإخراج أصبح `public/` بدلاً من `dist/`
