# دليل التثبيت

## المتطلبات

- Node.js v14+ و npm v6+
- بيئة تطوير (مثل VS Code)

## خطوات التثبيت

1. استخرج الحزمة أو استنسخ المستودع
2. افتح الطرفية في مجلد المشروع
3. نفّذ:

```
npm install
```

4. لتشغيل وضع التطوير (إعادة التجميع التلقائية):

```
npm run watch
```

أو لتجميع مرة واحدة:

```
npm start
```

## استكشاف الأخطاء الشائعة
- إذا ظهر خطأ "npm: command not found"، ثبت Node.js
- إذا فشل التجميع، احذف `node_modules` وأعد تثبيت الحزم
