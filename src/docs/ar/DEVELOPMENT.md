# دليل التطوير

## إعداد بيئة التطوير

- ثبت Node.js v14+ و npm
- افتح المشروع في VS Code
- ثبت الحزم: `npm install`

## سير العمل

1. عدّل المصادر (`index.pug`, `assets/`, `locals/`)
2. شغّل `npm run watch` لمراقبة التغييرات وإعادة التجميع
3. معاينة ملفات HTML المولدة في المتصفح

## إضافة قسم جديد

1. أضف القسم في `index.pug`
2. أضف مفاتيح الترجمة في `locals/en.json` و`locals/ar.json`
3. أضف أنماط في `assets/css/main.css`
4. احفظ وسيتم إعادة التجميع تلقائياً
